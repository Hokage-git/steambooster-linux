# SteamBooster для Linux

Неофициальная Linux-сборка открытого SteamBooster. Добавляет в клиент Steam кнопку пополнения, предложения для поддерживаемых игр, автоматическое восстановление инъекции и иконку управления в системном трее.

## Требования

- Linux x86_64 с пользовательскими службами systemd;
- установленный клиент Steam;
- Node.js 22 или новее (`node --version`);
- Python 3.11 или новее и PyQt6;
- `curl`, `systemctl`, `xdg-mime` (желательно).

Arch/CachyOS:

```bash
sudo pacman -S nodejs python-pyqt6 curl steam
```

Ubuntu/Debian: установите Node.js 22+ из поддерживаемого репозитория Node.js, затем:

```bash
sudo apt install python3-pyqt6 curl steam-installer
```

Fedora: Steam требует подключённый RPM Fusion:

```bash
sudo dnf install nodejs python3-qt6 curl steam
```

## Установка

1. Скачайте `SteamBooster-Linux-x86_64.zip` и `SHA256SUMS` со страницы Releases.
2. При желании проверьте архив: `sha256sum -c SHA256SUMS`.
3. Распакуйте ZIP.
4. Откройте терминал в распакованной папке и выполните:

```bash
./install.sh
```

Root-доступ установщику не нужен. Готовые файлы копируются в `~/.local/share/steambooster-linux`, поэтому распакованную папку после установки можно удалить.

Полностью завершите Steam и запустите `SteamBooster` из системного меню «Игры». При следующем входе в сеанс SteamBooster и трей будут запускаться автоматически.

## Управление

Иконка `B` в трее показывает состояние:

- зелёная — Booster и кнопка пополнения работают;
- жёлтая — выполняется восстановление;
- красная — требуется ручной перезапуск Booster;
- серая — Steam не запущен.

Перезапуск Booster через трей не завершает Steam или запущенные игры.

## Удаление

```bash
steambooster-uninstall
```

Удаляются только файлы этой сборки. Steam, игры и данные аккаунта не удаляются.

## Диагностика

```bash
systemctl --user status steambooster-launcher.service
journalctl --user-unit steambooster-launcher.service
```

Основной лог: `~/.local/share/steambooster-linux/docs/artifacts/logs/launcher.log`.

Если Steam уже был запущен без CDP, полностью завершите его штатным способом и снова откройте SteamBooster из категории «Игры».

Надпись «Скоро» остаётся нормальной для игр, по которым backend не предлагает покупку. Для поддерживаемых игр отображаются цена и кнопка покупки.
